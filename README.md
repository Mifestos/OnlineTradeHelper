2. Структура распределения настроек и конфигурацийВ целях обеспечения информационной безопасности и масштабируемости, управление конфигурацией строго разделено на три изолированных уровня:Системные секреты и доступы (Файл .env): Пароли от баз данных, приватные API-токены брокёров, сетевые адреса портов. Исключены из системы контроля версий (.gitignore).Интерактивные параметры расчета (HTTP-сессия): Ползунки уровня риска (\(\gamma \)), выбранные галочками тикеры акций, горизонт прогнозирования. Передаются на лету из браузера пользователя в виде динамического JSON.Долгосрочный профиль и лимиты (Таблицы БД): Максимальные/минимальные ограничения долей на одну акцию, расписание торгового робота. Хранятся в СУБД для обеспечения автономной работы робота без участия открытого браузера.3. Физическая топология папок и файлов проектаtextOnlineTradeHelper/

Стек применяемых технологийЯзык программирования: Python 3.12 (Среда выполнения и математические расчеты), JavaScript ES6+ (Фронтенд-интерфейс).Слой API / Веб-сервер: FastAPI, Uvicorn.Базы данных: TimescaleDB (PostgreSQL 16) — для хранения временных рядов свечей; Redis 7 (Alpine) — для оперативного кэширования цен.Искусственный интеллект и Математика: Facebook Prophet (Прогнозирование трендов), SciPy (Оптимизация матриц Марковица методом SLSQP), Pandas / NumPy (Анализ матриц ковариации).Интеграция с рынком: T-Invest API SDK (gRPC протоколы связи с Московской Биржей через экосистему Т-Банка).Инфраструктура: Docker, Docker Compose, Poetry.# OnlineTradeHelper
