# 📊 OnlineTradeHelper

**OnlineTradeHelper** — это событийно-ориентированная распределенная платформа для автоматизированного управления инвестиционным портфелем на Московской Бирже (MOEX) с использованием алгоритмов искусственного интеллекта.

---

## 🛠 1. Концептуальная схема взаимодействия

Система построена по классическому трехзвенному микросервисному принципу с разделением на горячий (**Streaming**) и холодный (**Analytics**) контуры обработки данных.

```text
┌─────────────────────────────────────────────────────────────────┐

│   • Веб-приложение: HTML5 / Асинхронный JavaScript (Vanilla JS)  │
│   • Графика: Интерактивные дашборды (Chart.js / ApexCharts)     │
└────────────────────────────────┬────────────────────────────────┘
                                 │
                    (HTTP POST JSON / REST API)
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────┐

└───────────────────────┬─────────────────▲───────────────────────┘
```

## ⚙️ 2. Структура распределения настроек и конфигураций

В целях обеспечения информационной безопасности и масштабируемости управление конфигурацией строго разделено на три изолированных уровня:

*   **🔒 Системные секреты и доступы (Файл `.env`):** Пароли от баз данных, приватные API-токены брокеров, сетевые адреса портов. Намертво исключены из системы контроля версий с помощью `.gitignore`.
*   **🎛 Интерактивные параметры расчета (HTTP-сессия):** Ползунки уровня риска (\(\gamma\)), выбранные галочками тикеры акций, горизонт прогнозирования. Передаются «на лету» из браузера пользователя в виде динамического JSON-пакета в теле запроса.
*   **🗄 Долгосрочный профиль и лимиты (Таблицы БД):** Максимальные/минимальные ограничения долей на одну акцию, расписание работы торгового робота. Хранятся в СУБД для обеспечения автономной работы воркеров без участия открытого браузера.

```text
OnlineTradeHelper/
├── .env                         # Файл секретов окружения (БД, токены API)
├── .gitignore                   # Запрет на публикацию секретов и кэша в Git

    ├── settings.py              # Инициализатор системных переменных проекта
    │

    │   ├── __init__.py
    │   ├── connection.py        # Асинхронный менеджер пулов TimescaleDB и Redis
    │   └── init_db.sql          # SQL-миграция структуры гипертаблиц
    │
    └── services/                # Микросервисная бизнес-логика
        ├── analytics/           # ИИ-Ядро системы
        │   ├── __init__.py
        │   ├── main.py          # FastAPI сервер, эндпоинты /predict и /optimize
        │   ├── models.py        # Классы ИИ-моделей (Prophet, алгоритмы-стратегии)
        │   └── optimiser.py     # Математический модуль SciPy
        │
        ├── streamer/            # Поток сбора данных (Инжектор)
        │   ├── __init__.py
        │   └── app.py           # Асинхронный gRPC клиент к API Т-Инвестиций
        │
        └── trader/              # Торговый робот-исполнитель
            ├── __init__.py
            └── bot.py           # Модуль сверки долей портфеля и выставления ордеров
```

## 🚀 4. Стек применяемых технологий

*   **Языки программирования:** Python 3.12 (Среда выполнения и математические расчеты), JavaScript ES6+ (Интерактивный фронтенд-интерфейс).
*   **Слой API / Веб-сервер:** FastAPI, Uvicorn (Асинхронная обработка сетевых запросов).
*   **Базы данных и Кэш:** TimescaleDB (PostgreSQL 16) — для хранения временных рядов свечей и тиков; Redis 7 (Alpine) — для мгновенного кэширования горячих цен.
*   **Искусственный интеллект и Математика:** Facebook Prophet (Прогнозирование трендов), SciPy (Оптимизация матриц Марковица методом SLSQP), Pandas / NumPy 1.x (Анализ матриц ковариации).
*   **Интеграция с рынком:** T-Invest API SDK (`t-tech-investments`) — gRPC-протоколы связи с Московской Биржей через экосистему Т-Банка.
*   **Инфраструктура:** Docker, Docker Compose, Poetry.
